BornSelection

This development of a microscopic model does not derive the Born Rule. It does show how using the complex amplitudes of interference in a microscopic model can result in a distribution of individual records close to the expected distribution calculated using the Born Rule.

Open index.html for the project guide. Read PROJECT_CONTEXT.txt before continuing research.

studies/2026-10-03 contains all current reports, plots, simulations and data.
reference contains preserved Claude notes, the earlier linear-response experiment and manuscript.

Current scripts require Python with numpy, scipy and matplotlib. Run scripts by their path; generated outputs are written alongside them. Copy an experiment before rerunning if preserving exact output bytes is important. Historical scripts are preserved and not revalidated as a standalone package during project creation.

The current chat has not been moved or duplicated. Add this folder as a local project in the app to use it for subsequent chats.
