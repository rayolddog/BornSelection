The earlier linear-response model changes the comparison

Review · 3 October 2026. Earlier source files were read, not modified. This is a source/code/results review, not a rerun of the earlier 84,000-event experiment.

Finding: The recovered Claude model deliberately separates linear complex excitation from stochastic commitment. The latest surface-basin model retained a linear complex response but replaced the successful event mechanism with equal integrated-response thresholds. It therefore tested a different selector and repeated a known stronger-site preference. Its failure does not refute the earlier linear-response-plus-race model.

What Claude's model did

dz/dt = −(γ+iωO)z + κ₁ exp(−iω₁t) + κ₂ exp(−iω₂t)
Pⱼ = |κⱼ|² / [(ωO−ωⱼ)²+γ²].

Putting the detector frequency at the midpoint gives equal response denominators. Couplings proportional to incoming amplitudes then produce squared-response ratios proportional to their squared magnitudes. Independent random event clocks, with rates proportional to those responses, determine the first record. This avoids a deterministic race to the same response threshold. Midpoint tuning, couplings, damping and the event law were explicitly left physically unexplained.

The claim that linearity removes interference needs narrowing. Linear amplitude evolution preserves superposition; taking the squared magnitude still gives cross terms. Distinct-frequency terms average away only with suitable time averaging or frequency resolution. Contributions to the same unresolved channel must still interfere.

The later transient implementation

dzⱼ/dt = −(γⱼ+iΔⱼ)zⱼ + ηⱼ ψⱼ s(t)[1+βξⱼ(t)]
λⱼ(t) = α |zⱼ(t)|²
Hⱼ(t) = ∫₀ᵗ λⱼ(s) ds
Eⱼ ~ Exp(1), independently; first Hⱼ(t) ≥ Eⱼ gives the record.

The code explicitly calls an exponential random generator for the thresholds. These thresholds are in cumulative hazard, not equal material activation barriers or equal accumulated energies. First-record stopping is post-selection exclusivity; it does not feed back to amplify the stronger channel before the first event.

Matched response gives zⱼ=ψⱼF(t), so λⱼ=wⱼh(t), wⱼ=|ψⱼ|² and Σwⱼ=1. The exact first-event formula is:

P(J=j, event by T) = wⱼ [1−exp(−H(T))]
P(J=j | event by T) = wⱼ.

Thus stronger channels are favored proportionately, rather than almost certainly. Identical time-dependent multiplicative noise shared by all channels preserves this result for every noise history. Independent local fluctuations need not preserve it exactly: survival must be calculated per history before averaging. Unequal susceptibilities change the detector response and generally change the probabilities.

Why suppression need not sharpen the bias

For constant rates, independent exponential clocks have P(T₁<T₂)=λ₁/(λ₁+λ₂). Stopping all other clocks after the winner is known cannot change that winner's identity. By contrast, deterministic equal thresholds give Tⱼ=q/λⱼ, so the higher rate always wins. Both mechanisms can suppress subsequent records, but their first-event distributions are radically different.

Therefore pre-threshold nonlinear inhibition is not required to obtain exclusivity with proportional first-event statistics. Adding it can undo the favorable structure. The appropriate distinction is between an unbiased post-event stop and competitive changes to the response or event timing before commitment.

What the earlier calculations established

The saved study contains 14 cases of 6,000 histories, totaling 84,000. Equal-response and tested fluctuation cases without fixed detuning disorder were compatible with input Born weights after the recorded multiple-comparison adjustment. Both detuning cases disagreed with uncorrected input weights but agreed with response-aware predictions in the saved validation. All 13 nonempty equal-power-threshold comparisons rejected the target distribution. Equal-response capture quadrature differed from its analytic value by at most 3.93×10⁻⁸. These are saved results inspected in this review, not new experimental evidence or new simulations.

Remaining physical question

The linear response explains squared-amplitude response scaling. The exponential cumulative-hazard thresholds supply the successful event statistics. The latter were not calculated from semiconductor or vacuum microstates. A proper continuation should retain this successful reference and ask whether physically derived fluctuations and commitment dynamics reproduce its survival law and channel competition. Drawing a complex Gaussian and taking its squared modulus can generate an exponential threshold mathematically, but does not explain why an actual detector thresholds that variable in cumulative hazard.

The failed recent threshold calculation should be retained as a negative control. It should not replace the recovered linear reference or justify adding stronger nonlinear competition without testing the resulting distortion.
